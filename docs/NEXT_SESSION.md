## משימות

סימון 👤 = משימה שרק אתה יכול לעשות.

### א. הכנה (לפני הכול)

- [ ] 👤 **A1.** Supabase לא מאפשר לערוך תבניות מייל בלי שרת דואר משלך, אז קודם מגדירים SMTP ורק אחר כך את התבניות:
  - **SMTP זמני דרך Gmail:** יוצרים סיסמת אפליקציה ב-myaccount.google.com/apppasswords (צריך שיהיה מופעל אימות דו-שלבי). ב-Supabase, תחת Authentication → Emails → SMTP Settings, ממלאים: `smtp.gmail.com`, פורט `465`, כתובת ה-Gmail כשם משתמש וכשולח, ואת סיסמת האפליקציה.
  - **תבניות:** מוסיפים `<p>Your code: <strong>{{ .Token }}</strong></p>` לתבניות "Magic Link" ו-"Confirm signup".
  - בלי זה אין כניסה. לפני פתיחה לציבור מחליפים את Gmail ב-Resend (משימה G1).
- [ ] 👤 **A2.** מפתח Anthropic: ב-[console.anthropic.com](https://console.anthropic.com) לטעון קרדיט, להגדיר תקרה חודשית וליצור מפתח. אחר כך, ב-Supabase תחת Edge Functions → Secrets, לשמור אותו כ-`ANTHROPIC_API_KEY`. לא להדביק את המפתח בצ'אט.
- [ ] **A3.** commit ראשון לגיט. אם תרצה, גם ריפו פרטי ב-GitHub.

### ב. הפיכה ל-PWA

- [ ] **B1.** לעדכן את ה-Blueprint בהחלטה (סעיף 0, סעיף 3.10 וסעיף 5): המסלול הוא PWA, ו-iOS native נדחה.
- [ ] **B2.** קובץ manifest (שם, אייקונים 192/512, `display: standalone`, צבעים) ותגיות Apple: `apple-touch-icon`, `apple-mobile-web-app-capable`, ו-`viewport-fit=cover`. לבדוק בתיעוד של Expo SDK 57 איך מזריקים אותם כשמשתמשים ב-`web.output: "single"`.
- [ ] **B3.** Service worker ששומר את מעטפת האפליקציה במכשיר, כדי שהיא תיפתח גם בלי רשת. זה מתאים להחלטה "אופליין לקריאה בלבד".
- [ ] **B4.** ליטוש לרשת:
  - שדה חיפוש במסך ההוצאות. `headerSearchBarOptions` לא עובד ברשת.
  - אישור מחיקה. `Alert.alert` לא עושה כלום ברשת.
  - שוליים בטוחים (safe area) לחריץ ולפס התחתון במצב מסך בית.
  - גודל גופן של 16px לפחות בשדות קלט, אחרת Safari מגדיל את המסך.
  - `inputMode="decimal"` בשדות סכום.
  - השלמת מיפוי האייקונים ל-Material בכל המסכים.
  - בדיקה במצב כהה.
- [ ] **B5.** פריסה לאירוח חינמי: `npx expo export --platform web`, והעלאה ל-Cloudflare Pages, Netlify או Vercel, עם הפניית SPA ל-`index.html`. 👤 לבחור ספק ולחבר חשבון.
- [ ] **B6.** 👤 להוסיף את כתובת האתר ב-Supabase, תחת Auth → URL Configuration (Site URL).
- [ ] **B7.** בדיקה על אייפון אמיתי: "הוסף למסך הבית", כניסה עם קוד במייל, הקמת משק בית, הצטרפות של בן הזוג עם קוד הזמנה, וסנכרון חי בין שני הטלפונים.
